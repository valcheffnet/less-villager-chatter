# Changelog

## 1.0.2

- Now also for Minecraft 1.20.1 on Fabric and Forge, and for 1.21.1, 1.21.11, 26.1.2 and 26.2 on Fabric and NeoForge. On Forge the settings are under Mods > Config.
- NeoForge 26.3: the game no longer stops at a loading warning about the mod's icon on start.

## 1.0.1

- Author name changed to SasnycoN. No gameplay changes.
- NeoForge build added, with the same features as the Fabric one. The settings are under Mods > Config.

## 1.0.0

First release, for Minecraft 26.3 on Fabric.

- Longer silence between idle "hmm" sounds, seperately for villagers and the wandering trader.
- Random start and variation, so villagers don't "hmm" in step.
- Volume for villager and trader sounds, set by the server for everyone, with an optional per-player override.
- Settings screen through Mod Menu.
